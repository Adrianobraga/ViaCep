### Projeto: Consumo da API VIACEP
O projeto consiste em criar os componentes necessários para carregar informações obtidas via API.
Todos os elementos repetitivos como Imagens, botões, cards, etc, devem ser renderizados através de componentes próprios.

#### Requisitos
* Utilizar  para estilização. Tenha atenção para exibição em ambientes desktop ou mobile.
* Todo conteúdo deve ser carregado via API ou ambiente externo, a aplicação deve consumir o conteúdo e customizar a exibição do mesmo.
* Utilizar Contexto e Reducer
* Utilizar todos os recursos de busca disponíveis na API.

#### Requisitos específicos 

* Após carregar o endereço com a API, aplicação deve mostrar um botão para traçar rota da posição atual do usuário (pelo browser) até o endereço selecionado.
* A rota deve ser criada utilizando o openLayers
